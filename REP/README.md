# 📚 Estudos e Exercícios de Front-End

Repositório dedicado ao armazenamento de exercícios práticos, anotações e pequenos projetos desenvolvidos durante meus estudos da tríade fundamental da web: **HTML5**, **CSS3** e **JavaScript**.

---

## 🎯 Objetivos

- Praticar a lógica de programação utilizando **JavaScript puro** (Vanilla JS).
- Dominar a estruturação semântica de páginas web com **HTML5**.
- Criar layouts modernos, adaptáveis e responsivos com **CSS3** (Flexbox, CSS Grid e Media Queries).
- Exercitar a manipulação do DOM e a criação de interfaces interativas sem o uso de frameworks.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação e marcação semântica.
* **CSS3:** Estilização, componentes visuais, animações e responsividade.
* **JavaScript (ES6+):** Manipulação de elementos do DOM, consumo de APIs nativas, manipulação de eventos e lógica da aplicação.
